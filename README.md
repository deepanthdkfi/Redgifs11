# ⚡ SoulX Browser — Next-Gen Clean & Powerful Web Browser

Inspired by the iconic **Soul Browser**, **SoulX Browser** is a lightweight, ultra-customizable, gesture-driven browser designed with a modern trending UI/UX (Glassmorphic dark/light aesthetics, gesture navigation, media sniffing, custom video player, built-in AdBlock, and distraction-free reader mode).

---

## 🌟 Key Features & Superpowers (Benefits)

### 1. 🎯 Ultra-Clean Trending UI & UX
- **Glassmorphism & Pitch OLED Dark Theme**: Immersive modern visual look with neon accents and silky-smooth animations.
- **Customizable Bottom Toolbar**: Soul Browser's signature navigation bar (Back, Forward, Home, Tabs Manager, Media Sniffer, Quick Menu Sheet).
- **Gesture Navigation**: Swipe left or right along the bottom navigation bar to switch between tabs instantly.

### 2. 🎥 Powerful Media Sniffer & Batch Downloader
- **Automatic Sniffing**: Detects high-resolution videos (`.mp4`, `.webm`, `.m3u8`), audio tracks (`.mp3`, `.wav`), and gallery images automatically.
- **1-Click Download**: Directly download any media file with automatic format parsing.
- **Batch ZIP Image Downloader**: Select multiple or all photos on a webpage and package them into a single `.zip` file on the fly!

### 3. 🎬 Built-in Soul Gesture Video Player
- **Brightness Swipe**: Vertical drag on the left half of the screen adjusts screen brightness.
- **Volume Swipe**: Vertical drag on the right half of the screen controls audio volume.
- **Smooth Seeking**: Intuitive scrubber and 10-second skip buttons.
- **Variable Playback Speed**: 0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x, 3x speeds.
- **Aspect Ratio Modes**: Fit, Cover, 16:9, Stretch.
- **Instant Frame Snapshot**: Capture exact video frames into crisp PNG images.
- **Background Play & Loop**: Seamless background audio playback and infinite repeat.

### 4. 🛡️ Soul Clean AdBlock & Privacy Engine
- **Intelligent Ad Blocking**: Strips banner ads, video overlays, tracking scripts, and popups.
- **Protection Levels**: `Strict`, `Standard`, and `Off` toggles.
- **Live Stats**: Displays blocked ads count and estimated data saved in MB.
- **Secret / Incognito Mode**: Fully isolated private tabs with zero history or cookie trace.

### 5. 📖 Distraction-Free Reader Mode with Text-to-Speech (TTS)
- Cleans cluttered news sites into a clean, readable article.
- Customizable font sizes, typography (Serif, Sans, Mono), and color palettes (Warm Sepia, Clean Light, Dark Slate, Pitch OLED).
- **Voice Read Aloud**: Built-in speech synthesizer reads articles aloud hands-free with speed control.

### 6. 🗂️ Advanced Tab Switcher
- Isolated Standard Tabs vs Incognito Secret Tabs.
- Multiple view layouts: **3D Card Grid**, **Stack View**, and **Compact List**.
- Quick Tab search, Close All, Duplicate, and New Tab creation.

### 7. 🛠️ Power Tools & Utilities
- **QR Code Sharing**: Instant QR code generator to scan and open URLs on your mobile smartphone.
- **DOM Inspector & Source Code Viewer**: Formatted HTML viewer with 1-click copy & download.
- **Page Snapshot**: High-definition viewport capture.
- **Downloads Manager**: Categorized storage visualizer (Videos, Audio, Images, Docs).
- **Speed Dial & Start Page**: Customizable shortcut dials, live weather widget, and trending discovery topics.

---

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Build frontend
npm run build

# 3. Start SoulX Browser server
npm start
```

Open `http://localhost:3000` in your browser!
